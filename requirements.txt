# Geodesic Spline Editor — Python dependencies
#
# Required Python: >= 3.10 (tested on 3.10 - 3.12, Windows / Linux).
# All versions below are the ones the codebase is known to run on
# (not strict minimums — newer patch releases should be fine).
#
# For a fully reproducible install pin via pip-tools or uv:
#   pip install pip-tools && pip-compile pyproject.toml --output-file requirements.lock
#
# potpourri3d is the trickiest dep: it's a wrapper around
# geometry-central (C++) and requires pybind11 + a C++17 compiler
# on first install.  On Windows, MSVC 2022 Build Tools is the most
# reliable path.  On Linux, gcc >= 9.
# See: https://github.com/nmwsharp/potpourri3d
#
# This file installs the EDITOR runtime.  Numba is the optional JIT
# accelerator (~50-2000x speedup on hot paths) and is canonically
# declared as the ``jit`` extra in pyproject.toml; install it with:
#
#   pip install -r requirements.txt   # plain editor
#   pip install -e .[jit]             # add Numba (recommended)
#   pip install -e .[jit,dev]         # contributor setup

numpy>=1.24,<3
scipy>=1.10
pyvista>=0.42
vtk>=9.2
potpourri3d>=1.2

# Numba is the optional JIT accelerator (``@njit`` becomes a no-op
# if missing, but hot paths run 50-2000x slower).  Install via the
# ``[jit]`` extra in pyproject.toml — that is the canonical
# declaration, kept out of this file so we DO exercise the no-Numba
# code path on any plain ``pip install -r requirements.txt``.
